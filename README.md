# StrongFit Academia

Aplicação desktop desenvolvida em Python, PySide6 e SQLite para gestão de alunos, planos, mensalidades, pagamentos, congelamentos e relatórios da academia StrongFit.

## Estado atual

MVP 0.1:

- Estrutura do banco criada;
- Planos iniciais cadastrados automaticamente;
- Painel de visão geral;
- Cadastro e edição de alunos;
- Pesquisa por nome;
- Filtro por situação;
- Preparação dos módulos financeiros.

## Como executar

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
